# There Is Only Room for Heart

A responsive, editorial-style starter website for a breast cancer awareness campaign.

## Preview locally
Open `index.html` in a browser. Internet access is needed for Google Fonts and the remote Unsplash photos.

## Publish quickly with Vercel
1. Create a new repository on GitHub.
2. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository root.
3. Import the repository in Vercel.
4. In Vercel project settings, choose **Other** / static site if prompted, and leave the build command empty. Set the output directory to `.` if a directory is required.
5. Deploy.

You can also use GitHub Pages by enabling Pages from the repository's Settings and selecting the main branch / root.

## Before publishing
- Replace the founder placeholder with the founder's real story.
- Replace event placeholders with verified dates, descriptions, photos, and recaps.
- Add real campaign contact details and social profiles.
- Connect the interest form to a form service such as Formspree or Netlify Forms. The current form is a front-end demo and does not send/store submissions.
- Check that you have permission to use any photos you add.
- Review medical content and retain links to reliable medical sources.

## Files
- `index.html` — page structure and content
- `styles.css` — visual design and responsive layout
- `script.js` — mobile navigation and demo form response
